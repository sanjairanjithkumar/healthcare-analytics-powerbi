# 🏥 Healthcare Analytics Dashboard | Excel & Power BI

🏥 A complete **Healthcare Analytics Dashboard** developed using **Microsoft Excel and Power BI** to analyze healthcare operations, appointments, insurance claims, and pharmacy inventory.

The dashboard provides an interactive view of key healthcare KPIs and helps identify operational trends, claim performance, and medicine stock requirements.

## 📌 Project Overview

This project was developed to transform raw healthcare data into a structured and interactive analytics dashboard.

The workflow was divided into two main stages:

**Microsoft Excel**

* 🧹 Data Cleaning
* 🔄 Data Preparation
* 🗂️ Data Organization

**Microsoft Power BI**

* 🗂️ Data Modeling
* 🧮 DAX Calculations
* 📊 Data Visualization
* 🎛️ Interactive Filters & Slicers
* 📈 Dashboard Development
* 💡 Business Insights

The final dashboard provides a consolidated view of **patients, appointments, insurance claims, and pharmacy inventory**.

# 📌 Key Healthcare KPIs

| KPI                      | Description                     |
| ------------------------ | ------------------------------- |
| 👥 Total Patients        | Total number of patients        |
| 📅 Total Appointments    | Total appointments recorded     |
| 🧾 Total Claims          | Total insurance claims          |
| ✅ Approved Claims        | Number of approved claims       |
| ❌ Rejected Claims        | Number of rejected claims       |
| 📊 Claim Approval Rate   | Percentage of approved claims   |
| 💰 Total Claim Amount    | Total value of submitted claims |
| 💵 Total Approved Amount | Total value of approved claims  |
| 💊 Total Medicines       | Number of medicines tracked     |
| 📦 Total Stock           | Current medicine inventory      |
| ⚠️ Low Stock Items       | Medicines requiring attention   |

> KPI values may change depending on the selected filters in the dashboard.

# 🔍 Key Insights

The dashboard enables analysis of:

* 👥 **Patient Activity** — Monitor overall patient volume and healthcare activity.
* 📅 **Appointment Performance** — Understand appointment status and consultation outcomes.
* 🧾 **Insurance Claims** — Compare approved and rejected claims and monitor approval rates.
* ❌ **Rejection Analysis** — Identify major rejection reasons.
* 💊 **Pharmacy Inventory** — Monitor medicine stock levels against reorder requirements.
* ⚠️ **Low Stock Monitoring** — Quickly identify medicines requiring attention.

* 📊 **Interactive Analysis** — Use filters and slicers to explore different segments of the data.
